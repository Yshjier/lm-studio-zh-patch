
提示词预处理器是一个在用户点击“发送”按钮时被调用的函数。它接收用户输入，并可以在输入到达模型之前对其进行修改。如果注册了多个提示词预处理器，它们会串联起来，每一个都会接收上一个的输出。

修改后的结果会被保存到聊天记录中，也就是说即使之后你的插件被禁用，被修改过的输入仍会被使用。

提示词预处理器只会对当前用户输入触发。它不会对聊天记录中此前的消息触发，即使那些消息并未经过预处理。

提示词预处理器接收一个用于控制预处理过程的 `ctl` 对象，以及需要预处理的 `userMessage`。它返回一个字符串或一个消息对象，用来替换该用户消息。
