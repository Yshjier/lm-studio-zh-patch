
`预览功能`

从 LM Studio 0.3.15 开始，你可以把你的预设发布到 LM Studio 社区。这让你能把自己的预设分享给他人，也能从其他用户那里导入预设。

此功能尚属早期，我们很希望听到你的反馈。请把 bug 和反馈发送至 bugs@lmstudio.ai。

---

## 已发布的预设

你在 LM Studio Hub 上分享的预设可以更新。

<img src="/assets/marketing/docs/preset-cloud-indicator.png" data-caption="你分享的预设会带有云朵图标标记。" />

## 第 1 步：做出改动并提交

对你的预设做任意改动，无论是已包含在预设中的参数，还是新增参数。

## 第 2 步：点击推送按钮

改动提交后，你会看到一个 `推送` 按钮。点击它即可把你的改动推送到 Hub。

推送改动会在 Hub 上生成你预设的一个新修订。

<img src="/assets/marketing/docs/preset-push-button.png" data-caption="点击推送按钮把你的改动推送到 Hub。" />
