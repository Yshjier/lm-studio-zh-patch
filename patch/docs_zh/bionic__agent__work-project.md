适用场景示例：

* 研究某个主题并对比多个来源。
* 总结笔记或文档。
* 起草并修改报告。
* 创建演示文稿或其他交付物。
* 构思并整理想法。
* 分析表格、文本和其他非代码文件。


## 一个简单的工作流

1. 新建一个项目。
2. 在新会话中附加文件，或描述 Bionic 应研究的内容。
3. 建议：向 Bionic 提出具体结果和文件格式要求。
4. 审阅回复和生成的文件。
5. 在同一会话中继续修改，或为独立任务开启新会话。

例如：

> 对比三份附加提案。写一份简洁的决策备忘录，包含建议、风险和对比表。保存为 `decision-memo.md`。

处理幻灯片或报告时，说明受众、篇幅、语气和输出文件名：

> 把这些会议记录做成一份 6 页的项目评审演示文稿。每页保持简洁，保存到工作区。

## 处理文档与文件

Bionic 可以处理文档、表格、演示文稿、PDF、图片和文本文件。可用的预览和编辑行为取决于文件格式。

打开右侧边栏查看项目工作区。

**项目文件**是由本项目管理的文件，包括你拖入 Bionic 的文件和 Bionic 创建的文件。

**外部文件**保留在原始位置，但 Bionic 可以直接访问。当 Bionic 编辑外部文件时，改动会直接写入该原始文件。
