### 搜索模型

你可以按关键词（例如 `llama`、`gemma`、`lmstudio`）搜索模型，或提供特定的 `user/model` 字符串。你甚至可以把完整的 Hugging Face URL 粘贴到搜索框中！

###### 小技巧：在 Mac 上按 `⌘` + `2`、在 Windows / Linux 上按 `ctrl` + `2`，即可从任意位置跳转到发现选项卡。

### 该选择哪个下载选项？

对于任意给定模型，你常常会看到若干选项，名称类似 `Q3_K_S`、`Q_8` 等。它们都是同一个模型的不同保真度版本。`Q` 代表一种称为"量化（Quantization）"的技术，大致意味着在牺牲一定质量的前提下压缩模型文件的体积。

如果你的机器性能足以运行，请选择 4 位或更高的选项。
