
使用 `lms runtime` 在不打开应用的情况下，列出、下载、切换或移除推理运行时。

### 命令

- `lms runtime ls` —— 列出已安装的运行时。
- `lms runtime get` —— 下载一个运行时。
- `lms runtime select` —— 设置活动运行时。
- `lms runtime remove` —— 卸载一个运行时。
- `lms runtime update` —— 更新已安装的运行时。

### 列出已安装的运行时

```shell
lms runtime ls
```

### 下载一个运行时

```shell
lms runtime get
```

### 切换到某个运行时

```shell
lms runtime select
```

按交互式提示选择你想要的版本。
