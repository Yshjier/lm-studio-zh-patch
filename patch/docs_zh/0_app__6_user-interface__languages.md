
得益于出色的社区本地化者，LM Studio 支持 `English`、`Spanish`、`Japanese`、`Chinese`、`German`、`Norwegian`、`Turkish`、`Russian`、`Korean`、`Polish`、`Vietnamese`、`Czech`、`Ukrainian`、`Portuguese (BR,PT)` 等多种语言。

<hr>

### 选择语言

你可以在"设置"选项卡中选择语言。

使用"偏好设置 > 语言"下的下拉菜单。

```lms_protip
你可以通过按下 macOS 上的 `cmd` + `,` 或 Windows/Linux 上的 `ctrl` + `,`，从应用中的任意位置跳转到"设置"。
```

###### 要进入"设置"页面，你需要处于 [Power User 模式](/docs/modes) 或更高级别。
