云端模型需要一个含有可用额度的 LM Studio 账户。本地模型和 LM Link 模型不消耗 Bionic 云端额度，也可以不登录 LM Studio 账户使用。

## 登录

1. 打开**设置**。
2. 在**通用**下找到**账户**。
3. 选择**登录**，在浏览器中完成登录。
4. 返回 Bionic。

## 为个人使用添加额度

![账单与用量设置，突出显示管理套餐](https://lmstudio.ai/assets/marketing/docs/bionic-general-manage-plan.png)

1. 在**设置**的**账户**下，选择**管理套餐**。
2. 页面会跳转到你在 LM Studio Hub 上的账户。在功能区导航到**云端推理**，为账户补充额度。
3. 完成结账，并确认**可用余额**已显示新的额度。
4. 返回 Bionic，打开**账单与用量**，刷新以确认新余额已显示。
