提示词预处理器（Prompt Preprocessor）是在用户点击“发送”按钮时调用的函数。它接收用户输入，并在输入到达模型之前对其进行修改。如果注册了多个提示词预处理器，它们会串联执行，每个预处理器接收上一个的输出。

修改后的结果会保存到聊天历史中，也就是说，即使之后禁用了你的插件，修改后的输入仍会被使用。

提示词预处理器只会对当前用户输入触发。对于聊天历史中的既往消息，即使它们未经预处理，也不会触发预处理器。

提示词预处理器接收一个用于控制预处理的 `ctl` 对象，以及需要预处理的 `userMessage`。它返回字符串或消息对象，用于替换用户消息。
