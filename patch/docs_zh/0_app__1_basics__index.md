## 快速上手

首先，**安装最新版本的 LM Studio**。你可以从[此处](/download)获取。

一切就绪后，你需要**下载你的第一个 LLM**。

### 1. 将 LLM 下载到你的电脑

前往"发现"选项卡下载模型。挑选一个精选选项，或通过搜索词（例如 `"Llama"`）搜索模型。关于下载模型的更多深入信息见[此处](/docs/basics/download-models)。

<img src="/assets/marketing/docs/discover.png" style="width: 500px; margin-top:30px" data-caption="LM Studio 中的发现选项卡" />

### 2. 将模型加载到内存

前往**聊天**选项卡，然后

1. 打开模型加载器
2. 选择你已下载（或[侧载](/docs/advanced/sideload)）的模型之一。
3. 可选地，选择加载配置参数。

<img src="/assets/marketing/docs/loader.png" data-caption="在 macOS 上用 `cmd` + `L`、在 Windows/Linux 上用 `ctrl` + `L` 快速打开模型加载器" />

##### "加载模型"是什么意思？

加载模型通常意味着分配内存，以便在你的电脑 RAM 中容纳模型的权重和其他参数。

### 3. 开始聊天！

模型加载后，你就可以在聊天选项卡中与模型开始一来一回的对话了。

<img src="/assets/marketing/docs/chat.png" data-caption="macOS 上的 LM Studio" />
