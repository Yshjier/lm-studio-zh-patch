[Locally](https://apps.apple.com/us/app/locally-ai-local-ai-chat/id6741426692) 是 LM Studio 的移动应用，适用于 iPhone 和 iPad。在 Locally 中启用 LM Link，即可直接在手机上使用运行于 LM Studio 的最大本地模型。设备间的所有数据和通信均保持端到端加密。

![iPhone 上通过 LM Link 使用 Locally](https://lmstudio.ai/assets/marketing/blog/locally-lm-link.png)

## 开始使用

1. 如果还没有 LM Studio，[在此下载](/download)。
2. 登录你的 LM Studio 账户，并确保 LM Studio 中已启用 LM Link。
3. 在 iPhone 或 iPad 上[下载 Locally 应用](https://apps.apple.com/us/app/locally-ai-local-ai-chat/id6741426692)。
4. 使用与 LM Studio 相同的账户登录 Locally，并在 Locally 中启用 LM Link。

你的 Locally 设备和 LM Studio 设备会通过链路相互发现，随后即可直接在手机上使用运行于 LM Studio 的最大模型。

## 常见问题

<details>

<summary>关闭 Locally 应用后连接还会保持吗？</summary>

LM Link 是设备之间一条存活的端到端加密连接。虽然这保证了安全性，但应用进入后台后，连接能维持多久存在限制。我们正在积极改进重连延迟，并探索保持连接存活的方式。

</details>

<details>

<summary>LM Link 需要互联网连接吗？</summary>

需要。LM Link 需要互联网连接才能在设备之间建立连接。

</details>

<details>

<summary>我看到 Locally 也支持 Mac。可以在 iPhone 版和 Mac 版 Locally 之间使用 LM Link 吗？</summary>

不能完全这样用——LM Link 的设计是把电脑上的 LM Studio 连接到移动设备上的 Locally，而不是连接两个 Locally 应用。

</details>
