项目把相关的会话和文件归集在一起。为需要共享同一目标、源文件或代码库的工作创建一个项目。

## 创建项目

1. 新建一个项目并为其命名。
2. 若希望 Bionic 处理本地代码库，打开**允许编码**开关。
3. 启用编码后，选择**选择 Bionic 的工作文件夹**，并选定代码库的根目录。
4. 点击**创建**。
5. 在新会话中，若 Bionic 尚未选定**根模型**，请选择一个模型。
6. 告诉智能体你想做什么。

## 处理文档与文件

附加或拖入文件和文件夹以添加素材。Bionic 创建的文件会出现在右侧边栏的**项目文件**下。项目文件在同一项目的所有会话间共享。

例如：

> 研究这些笔记中的各个方案，总结取舍，并把建议保存为 `recommendation.md`。

更多内容见[处理文档](/docs/bionic/agent/work-project)。

## 处理代码库

启用**允许编码**后，Bionic 可以在选定的工作目录中搜索仓库、编辑文件、使用 Git 并运行 shell 命令。

例如：

> 找出请求超时是在哪里处理的。解释当前行为，修复失败的边界情况，并运行相关测试。

保留改动前，请先审阅 Bionic 的差异和命令输出。

更多内容见[编码](/docs/bionic/agent/code-project)。

## 让任务保持聚焦

给 Bionic 明确的目标、相关文件和具体产出。对于较大的工作，先让它调查，再在同一会话中实施。

参见[项目与会话](/docs/bionic/projects-and-sessions)以组织更多工作。
