## 打开代码库

1. 新建一个项目并为其命名
2. 打开**允许编码**开关
3. 选择**选择 Bionic 的工作文件夹**
4. 选定代码库的根目录。
5. 点击创建

之后如需更换文件夹，可在右侧边栏查看当前工作目录。在工作目录选项中选择**更换工作目录…**。

Bionic 会为所选文件夹建立索引，以便搜索项目文件。若该文件夹是 Git 仓库，文件面板还会显示仓库和当前分支。

## 可以让 Bionic 做什么

编码项目支持以下任务：

* 查找某个功能是如何实现的。
* 调试失败的行为。
* 跨多个文件重构代码。
* 实现一个功能。
* 添加或更新测试。
* 更新文档。
* 审阅跨文件改动。

例如：

> 找出校验上传图片的代码。解释当前流程，为新的尺寸限制添加支持，更新测试，并只运行相关测试套件。

## 采用“检视—改动—测试”的工作流

为获得更稳妥的结果：

1. 让 Bionic 检视仓库并解释相关代码。
2. 确认预期改动和约束条件。
3. 让它编辑文件。
4. 让它运行聚焦的测试或检查。
5. 审阅行内差异和你的 Git 差异。

对于大型任务，让 Bionic 把调查拆成更小的部分。必要时它可以搜索仓库，并使用子会话并行调查。
