
要分享或发布你的 LM Studio 插件，在终端中打开插件目录并运行：

```bash
lms push
```

该命令会打包你的插件并上传到 LM Studio Hub。你可以用它创建新插件或更新已有插件。

### 修改插件名称

如果你想修改插件名称，可以编辑插件目录根部的 `manifest.json` 文件。找到 `name` 字段，改成你想要的名字。注意 `name` 必须使用 kebab-case（短横线分隔的小写）命名。

当你执行 `lms push` 时，如果名称已改变，它会被当作一个新插件。如果不再需要旧插件，你可以从 LM Studio Hub 中删除它。

### 把插件发布到组织

如果你属于某个组织，并希望把插件发布到该组织，可以编辑插件目录根部的 `manifest.json` 文件。找到 `owner` 字段，把它设置为你组织的名称。运行 `lms push` 时，插件会发布到该组织而不是你的个人账号。

### 私有插件

如果你的账号支持私有插件，可以在运行 `lms push` 时加上 `--private` 标志来私下发布插件：

```bash
lms push --private
```
