
LM Studio 拥有一个类似 ChatGPT 的界面，用于与本地 LLM 聊天。你可以创建许多不同的对话线程，并在文件夹中管理它们。

<hr>

### 创建新聊天

你可以点击 "+" 按钮创建新聊天，或使用快捷键：Mac 上为 `⌘` + `N`，Windows / Linux 上为 `ctrl` + `N`。

### 创建文件夹

点击新建文件夹按钮，或按以下快捷键创建新文件夹：Mac 上为 `⌘` + `shift` + `N`，Windows / Linux 上为 `ctrl` + `shift` + `N`。

### 拖放

你可以把聊天拖入或拖出文件夹，甚至可以把文件夹拖入文件夹！

### 复制聊天

你可以点击 `•••` 菜单并选择"复制"来复制整个聊天对话。如果聊天中包含任何文件，它们也会被一并复制。

### 聊天分屏视图

你可以把聊天标签拖放到窗口的任一半，从而并排查看两个聊天。或者，使用聊天窗口右上角的分屏图标向左或向右分屏。

用每个窗格右上角的 'x' 按钮关闭分屏视图的一侧。

## 常见问题

#### 聊天在文件系统中存储在哪里？

右键点击一个聊天，然后选择"在访达中显示" / "在文件资源管理器中显示"。
对话以 JSON 格式存储。**不**建议手动编辑它们，也不建议依赖其结构。

#### 模型会从聊天中学习吗？

模型不会从聊天中"学习"。模型只"知道"聊天中存在的内容，或通过"系统提示"等配置选项提供给它的内容。

## 对话文件夹的文件系统路径

Mac / Linux：

```shell
~/.lmstudio/conversations/
```

Windows：

```ps
%USERPROFILE%\.lmstudio\conversations
```
