
```lms_notice
一般来说，LM Studio 不需要联网即可工作。这包括与模型聊天、与文档聊天、运行本地服务器等核心功能，它们都不需要联网。
```

### 不需要联网的操作

#### 使用已下载的 LLM

一旦 LLM 已存在于你的机器上，模型就会本地运行，你完全可以离线使用。你在 LM Studio 中与 LLM 聊天时输入的任何内容都不会离开你的设备。

#### 与文档聊天（RAG）

当你把文档拖放到 LM Studio 中与其聊天或执行 RAG 时，该文档会留在你的机器上。所有文档处理都在本地完成，你上传到 LM Studio 的任何内容都不会离开该应用。

#### 运行本地服务器

LM Studio 可作为服务器，在 localhost 或局域网中提供 LLM 推理。对 LM Studio 的请求使用 OpenAI 端点并返回类 OpenAI 的响应对象，但一切都留在本地。

### 需要联网的操作

以下若干操作依赖网络连接。一旦 LLM 已存在于你的机器上，你完全可以离线使用。

#### 搜索模型

当你在"发现"选项卡中搜索模型时，LM Studio 会发起网络请求（例如访问 huggingface.co）。没有网络连接时搜索将无法工作。

#### 下载新模型

要下载模型，你需要稳定（且速度尚可）的网络连接。你也可以"侧载"模型（使用在应用之外获取的模型）。参见[侧载模型](/docs/advanced/sideload)的说明。

#### "发现"选项卡的模型目录

LM Studio 的每个版本都内置了一份初始模型目录。目录中的条目通常接近于我们发布该版本时刻的在线目录状态。不过，为了展示每个模型的统计信息和下载选项，我们需要发起网络请求（例如访问 huggingface.co）。

#### 下载运行时

[LM Runtime](advanced/lm-runtimes) 是单独打包的软件库，即 LLM 引擎，用于运行某些格式的模型（例如 `llama.cpp`）。自 LM Studio 0.3.0 起（见[公告](https://lmstudio.ai/blog/lmstudio-v0.3.0)），无需完整更新 LM Studio 即可轻松下载甚至热切换运行时。要检查可用运行时并下载它们，我们需要发起网络请求。

#### 检查应用更新

在 macOS 和 Windows 上，LM Studio 内置了一个功能完善的应用更新器。Linux 的应用内更新器[仍在开发中](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/89)。当你打开 LM Studio 时，应用更新器会发起网络请求以检查是否有新更新。如果有新版本，应用会显示通知，让你选择立即更新或稍后更新。
没有网络连接时，你将无法通过应用内更新器更新应用。
